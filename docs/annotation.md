# Guide d'annotation

Pour que deux relecteurs saisissent la même chose. En cas de doute, choisir la règle ci-dessous et l'écrire dans la note.

| Champ | Règle |
| --- | --- |
| Catégorie | **Batteries** : stockage seul. **Batteries + solaire/éolien** : stockage couplé à une production sur le même site. **Poste pour batteries** : poste privé construit pour raccorder du stockage. **Data center**. Pour le reste : poste pour solaire ou éolien seul, poste public ou rénovation, batteries usagées (déchets), autre. |
| Porteur | La **dénomination** de la société qui dépose, telle qu'écrite (« APAL MW »), sans « la société » ni la forme juridique. Jamais une personne physique : si le dépôt est fait par une personne, laisser vide. |
| SIRET | Les 14 chiffres de la société qui dépose, sans espaces. Vide s'il n'est pas dans les documents. |
| Commune | La commune d'implantation. Si le projet est sur plusieurs communes, la première citée. |
| Puissance (MW) | La puissance **maximale déclarée** du projet, en MW (MWac si les deux sont donnés). Vide si elle n'est pas écrite : ne jamais la calculer. |
| Puissance min (MW) | Seulement si le document donne une fourchette (« 10-20 MW » donne 10). Sinon, la même valeur que la puissance. |
| Énergie (MWh) | La capacité de stockage déclarée. |
| Poste | Le **nom** du poste de raccordement (« Margot », « Les Hoquins »). Seulement la tension (« 400kV ») si aucun nom n'est donné. Vide pour un simple poste de livraison. |
| Déposé le | La date de **dépôt complet** du dossier, pas la date de la décision. |
| Décision | Soumis ou non à étude d'impact, d'après l'article 1 de la décision. « En attente » s'il n'y a pas encore de décision. |

**Champ vide** : l'information est absente des documents. C'est une réponse, pas un oubli : la machine sera comptée fausse si elle invente une valeur.

**Cause** (en cas de correction) :
- **lecture / OCR** : texte mal lu ;
- **mise en page** : formulaire d'un format non prévu ;
- **règle** : l'information était lisible mais mal extraite ;
- **classement** : mauvaise catégorie ;
- **fusion** : mauvais document retenu entre formulaire et décision ;
- **document** : le document lui-même est ambigu ou faux.

**À l'aveugle** : saisir depuis le PDF seul, sans chercher à retrouver la valeur de la machine.
